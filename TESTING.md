# Arcane Genesis Launcher 0.4.1 — результаты проверки

Актуальный выпуск: Launcher 0.4.1 со встроенным рецептом сборки 0.3.4. Выпуск 0.4.0 сохранён неизменным, но не подключался к автообновлению из-за обнаруженного сбоя длинных путей.

## Подтверждено

- 73 проверки ядра: подписи и хеши, защита пользовательских файлов, отмена, повторное скачивание, восстановление прерванного обновления и запрет отката на устаревший выпуск.
- 17 проверок интерфейса, включая реальные обработчики восстановления повреждённого состояния.
- Реальный EXE 0.4.1 установлен в папку с кириллицей длиной 152 символа. Проверены обновление повреждённой библиотеки с атрибутом только чтение, отказ от удаления по подменённому списку, сохранение личных настроек и мира при удалении. Временные каталоги очищены.
- Чистый исходный архив проверен на отсутствие приватных материалов. В GitHub Actions используется закреплённый архив .NET SDK с проверкой SHA512, затем выполняются тесты и независимая сборка Windows-установщика. Приватный ключ подписи на GitHub не передаётся.
- Опубликованный модпак 0.3.4: 384 файла, 127 внешних загрузок и 257 ссылок на собственные файлы (249 уникальных объектов). Размеры и SHA256 всех 249 опубликованных объектов совпали с данными GitHub. Один опубликованный собственный JAR дополнительно скачан и проверен; подпись активного канала проверена кодом лаунчера.
- До публикации Minecraft 1.21.1 / NeoForge 21.1.265 с новой сборкой открыл отдельный тестовый мир, интегрированный сервер загрузился, игра завершилась с кодом 0. Игровая среда в этом испытании скопирована из проверенного кеша, а не скачана заново.
- В игре подтверждены Passive Skill Tree: 64 очка, опыт от 200 до 8000, штраф амнезии 0; пустой список администраторов JourneyMap и ограничения запросов QuickSkin. Проверены шесть выбранных файловых ресурспаков и ресурсы собственных модов.

## Ограничения

Другой физический Windows-ПК и выделенный сервер с несколькими игроками проверяет владелец. Интеграция Iron’s Spells исключена из текущего задания. Полное прохождение кампании и каждая способность/босс не проверены.

Независимая сборка на GitHub — это проверка компиляции и тестов, а не испытание игры на отдельном физическом ПК. Доступность внешних источников проверена для всех 127 адресов, но повторное скачивание всех этих файлов в данном этапе не заявлено.

Установщик не подписан сертификатом Authenticode. Манифесты обновлений подписаны RSA-PSS/SHA256; SHA256 установщика прилагается к релизу. Тестовый фоновый скриншот не является измерением FPS.

NeoForge этой версии использует общие SERVER-конфигурации из config; существующие world/serverconfig могут их переопределять. Пользовательские настройки мира сохраняются.
