# Arcane Genesis Launcher 0.3.0 — результаты проверки

Выпуск опубликован: https://github.com/Lycean415/ArcaneGenesis-Releases/releases/tag/launcher-0.3.0
Установщик: 80 646 144 байта.
SHA256: c96deb98c0ce99895303923ade02cc2d9709be8d1f79f51acf2d4cfbc97eef00

## Подтверждено

- 21 автоматическая проверка обновления, подписей, контрольных сумм, восстановления после сбоя, блокировок, защиты миров/настроек и переноса прежних адресов. Тесты прошли локально и на отдельном Windows-агенте GitHub.
- На GitHub Windows Server 2025 установлены SDK из официального источника, собраны исходники, приложение и автономный Windows-установщик. Это независимая сборка вне домашнего ПК.
- В пустой тестовой папке скачаны Java 21 Temurin, официальный клиент Minecraft 1.21.1, библиотеки и ресурсы Mojang. NeoForge 21.1.265 установлен оригинальным официальным установщиком. Файлы домашней Minecraft-установки не импортировались.
- 4037 файлов игровой среды, 107 элементов classpath, 8 модульных библиотек. После установки повторная проверка среды прошла без сети.
- Окончательный модпак: 396 файлов, включая 130 JAR модов. 127 внешних загрузок — официальные источники; 269 файлов проекта встроены в установщик. В отдельном чистом игровом каталоге все файлы установлены заново. Minecraft создал отвечающее окно, загрузился за 40.333 секунды и штатно завершился с кодом 0.
- Подписи обоих опубликованных каналов проверены. Манифест сборки совпадает со встроенным комплектом. Размеры и SHA256 всех 269 объектов в GitHub Releases совпали.
- Реальный тест восстановления: один JAR нашего мода в тестовой установке намеренно повреждён и восстановлен с GitHub. Скачан только один файл; 389 файлов не изменены, 6 пользовательских конфигураций сохранены.
- Именно опубликованный установщик скачан и сверён с SHA256 GitHub. Он успешно установлен в папку с русскими буквами и пробелами: 755 файлов лаунчера, код завершения 0. Отрендерен интерфейс установленного приложения с оригинальным логотипом и кнопками.
- Перед публикацией исключены 63 файла кешей/истории/аппаратного отпечатка. Аудит исходного архива PASS. В опубликованном комплекте нет миров, приватных ключей, учётных данных, персональных настроек скина и диагностических модов.

## Ограничения

Игра запускалась в новой папке на текущем Windows-компьютере. GitHub подтвердил независимую компиляцию на Windows Server, но это не тест запуска Minecraft на отдельном чистом Windows 10/11 ПК. Такое испытание ещё не проводилось.

Не выполнены полное прохождение кампании, все игровые способности/устройства/боссы, проверка каждой графической детали и нагрузка нескольких игроков. Сторонние моды оставляют предупреждения о ресурсах и тайм-ауты собственных проверок новых версий; они не помешали подтверждённому запуску.

Установщик не подписан сертификатом Authenticode. Подписаны манифесты обновлений; первоначальную загрузку следует сверять по SHA256 со страницей релиза.

Исходный архив выпуска неизменяемый и содержит документы, написанные на этапе подготовки. Актуальная инструкция: INSTALL.md в репозитории. Постоянные каналы уже опубликованы и проверены.
