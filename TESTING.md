# Arcane Genesis Launcher 0.4.2 — результаты проверки

Исправлено зависание проверки Java при запуске через интерфейс WPF. Синхронный интерфейс проверки больше не захватывает поток окна при ожидании вывода процесса Java. Проверка игровых файлов и запуск вынесены в фон; сохраняются прежние проверки целостности, версии Java и разрядности.

## Проверки перед публикацией

- Старая версия воспроизводимо заблокировалась в тесте с контекстом интерфейса. Исправленная проверка той же настоящей Java 21 завершилась за 90 мс.
- Реальный обработчик кнопки «Играть» запустил Minecraft 1.21.1 / NeoForge 21.1.265 в отдельном профиле; тестовый мир загрузился, игра завершилась с кодом 0. За время запуска зафиксированы 64 ответа потока интерфейса. Полное испытание заняло около 59,5 секунды.
- 73 проверки ядра и 17 функциональных проверок интерфейса прошли.
- Проверка исходного архива: 290 файлов; приватные ключи, миры, диагностические программы, журналы и приватные материалы аудита исключены.
- Сохраняются исправления длинных путей Windows и очистки резервных файлов. В версии 0.4.1 опубликованный установщик прошёл реальную установку, восстановление библиотеки с атрибутом только чтение и удаление в папке с кириллицей длиной 152 символа. Пользовательские настройки и тестовый мир сохранились.

## Ограничения

Сборка остаётся 0.3.4. Игра в текущем испытании использовала ранее проверенный кеш среды. Проверка компиляции на Windows GitHub не является испытанием Minecraft на другом физическом ПК.

Другой физический Windows-ПК и выделенный сервер с несколькими игроками проверяет владелец. Интеграция Iron’s Spells исключена из текущего задания. Полное прохождение кампании и каждая способность/босс не проверены.

Установщик не имеет Authenticode. Манифесты обновлений подписаны RSA-PSS/SHA256; точный SHA256 установщика прилагается к релизу. Приватный ключ подписи не передаётся в GitHub Actions.
