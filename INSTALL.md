# Установка Arcane Genesis

1. Скачайте ArcaneGenesis-Setup-0.3.0.exe из релиза launcher-0.3.0.
2. Установите лаунчер и откройте Arcane Genesis.
3. Введите ник, при необходимости выберите папку игры и память в настройках.
4. Нажмите «Установить», дождитесь загрузки, затем «Играть».

Java 21, Minecraft 1.21.1, NeoForge 21.1.265 и моды скачиваются автоматически. Наши файлы и резервный подписанный манифест встроены в установщик. Prism не требуется. Интернет необходим для первой установки и обновлений. Миры и личные настройки сохраняются.

Windows 10/11 x64, рекомендуются 16 ГБ RAM и 8 ГБ свободного места. По умолчанию игре выделено 7 ГБ RAM.

Папка игры по умолчанию: %LOCALAPPDATA%/ArcaneGenesis/Game/game. Проверка и восстановление файлов находятся в настройках. Логи: game/logs/launcher-error.log и game/logs/latest.log; установка NeoForge: runtime/bootstrap/neoforge-install.log.

Каналы сборки и лаунчера независимы и подписаны. Старые адреса локального компьютера заменяются автоматически. Первую установку можно завершить из встроенного манифеста при временной недоступности GitHub.

Локальный профиль не предоставляет лицензию Minecraft или официальную онлайн-сессию. Полное игровое прохождение, нагрузка нескольких игроков и запуск на отдельном чистом физическом Windows-ПК ещё не проверены.

Исходники и инструкции внутри архива отражают состояние подготовки выпуска; эта страница содержит актуальный статус публикации.
