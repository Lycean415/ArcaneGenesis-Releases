Minecraft Java 1.21.1 · NeoForge 21.1.265 · Windows 10/11 x64.

Лаунчер самостоятельно скачивает Java, Minecraft, NeoForge и сторонние моды из официальных источников. Файлы проекта и резервный подписанный манифест встроены в установщик. Prism не требуется. Каналы обновлений сборки и лаунчера независимы и подписаны.

Проверены независимая сборка на GitHub Windows, установка в пустую игровую папку, реальный запуск Minecraft и восстановление одного повреждённого файла с загрузкой только этого файла. Отдельный чистый физический Windows-ПК и полное прохождение пока не тестировались.

В опубликованном комплекте нет миров, кешей игроков, истории JEI, аппаратных отпечатков, персональных настроек скина, учётных данных и приватных ключей. Аудит: privacy-audit.json. Локальный профиль не предоставляет лицензию Minecraft или официальную онлайн-сессию.

Каналы: channels/pack/pack.json и channels/launcher/launcher.json. Не заменяйте опубликованные версии установщика: подписанный манифест привязан к точному SHA256 файла.
