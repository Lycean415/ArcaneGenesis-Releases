# Arcane Genesis Launcher 0.4.0

Исправлены установка и обновление на независимом Windows-ПК: официальная среда Minecraft 1.21.1 / NeoForge 21.1.265, проверка Java, подписанные манифесты, контроль целостности и восстановление прерванной установки. Сохранён фирменный интерфейс, локальный профиль и настройки памяти.

Установщик содержит рецепт сборки 0.3.4 и собственные файлы проекта. Minecraft, Java и сторонние моды скачиваются из исходных HTTPS-источников. Для первой установки нужен интернет. Локальный профиль не заменяет лицензию Minecraft.

Проверено до публикации: 73 проверки ядра, 17 проверок интерфейса, установка/обновление/удаление в отдельной папке с кириллицей, запуск Minecraft и интегрированного тестового мира. Повторная сборка чистого исходного архива также прошла. Тесты на втором физическом ПК и выделенном сервере проводит владелец; полное прохождение кампании не заявлено. Установщик не имеет Authenticode; контрольная сумма прилагается, каналы обновлений подписаны.

Разработка выполнена для Arcane Genesis с помощью Codex. Исходный код лаунчера распространяется по прилагаемой лицензии; условия сторонних модов сохраняются. Игровые файлы, учётные данные, миры и приватные материалы аудита в исходники не включены.
