# Arcane Genesis Launcher 0.4.2

Исправлено зависание при нажатии «Играть»: проверка Java больше не блокируется потоком интерфейса. Проверка игровых файлов и запуск Minecraft выполняются в фоне; интерфейс продолжает отвечать, строка состояния показывает текущий этап.

Подтверждено: старая проверка воспроизводимо зависала в отдельном тесте интерфейса; исправленная проверка той же Java завершилась за 90 мс. Реальный обработчик кнопки «Играть» запустил Minecraft, загрузил отдельный тестовый мир и завершил игру с кодом 0. За время запуска зарегистрированы 64 ответа потока интерфейса. 73 проверки ядра и 17 функциональных проверок интерфейса прошли.

Сохранены исправления длинных путей Windows и очистки резервных файлов. Сборка остаётся 0.3.4; переустановка модов не требуется. Закройте лаунчер и Minecraft перед обновлением. Игра, миры и личные настройки сохраняются.

Это установщик всей сборки с автоматическим скачиванием Minecraft 1.21.1, NeoForge 21.1.265, Java 21 и внешних модов из исходных HTTPS-источников. Для первой установки нужен интернет. Локальный профиль не заменяет лицензию Minecraft или официальную онлайн-сессию. Authenticode отсутствует; манифесты обновлений подписаны, SHA256 установщика прилагается.

Другой физический Windows-ПК, многопользовательская нагрузка и полное прохождение не проверены. Разработка выполнена для проекта с помощью Codex; условия сторонних компонентов сохраняются. Приватные ключи, игровые миры, диагностические программы и приватные материалы аудита в исходники не включены.
